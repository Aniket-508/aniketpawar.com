## Overview

Free, open-source PDF generation and manipulation components for React with shadcn/ui-compatible registry setup.

## The problem

Creating and processing PDFs in JavaScript often requires heavy libraries, complex configurations, and lacks composable, theme-aware components.

## Wins

Lightweight, composable PDF blocks with React-first API, theming support, and seamless integration with shadcn/ui workflows.
